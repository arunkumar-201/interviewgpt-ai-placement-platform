# User Personas

## InterviewGPT — AI Placement Preparation Platform

---

## Persona 1: Arjun — The Focused Final-Year Student

| Attribute | Detail |
|-----------|--------|
| **Age** | 21 |
| **Role** | B.Tech CS, final year |
| **Location** | Tier-2 city, India |
| **Tech comfort** | High — uses LeetCode, GitHub daily |
| **Placement timeline** | 4 months to campus drives |

### Background

Arjun has solved ~200 LeetCode problems but lacks confidence in system design and HR rounds. His resume gets few callbacks. He spends hours jumping between LeetCode, YouTube, and random Google Doc question lists.

### Goals

- Crack product-based companies (Google, Amazon, Microsoft)
- Improve resume ATS score above 80
- Get structured mock interview practice
- See one "readiness number" instead of guessing

### Frustrations

- No single view of weak areas
- Mock interviews feel generic
- Doesn't know if GitHub profile helps or hurts

### How InterviewGPT Helps

- Dashboard with Problems Solved, Resume Score, Interview Score, GitHub Score
- Company question bank filtered by Google/Amazon
- AI mock interviewer with role + company context
- Placement readiness roadmap targeting trees/graphs gap

### Key Features Used

Dashboard · DSA Arena · Resume Analyzer · Mock Interviewer · Company Bank · Readiness Engine

## Persona 2: Priya — The Resume-First Switcher

| Attribute | Detail |
|-----------|--------|
| **Age** | 24 |
| **Role** | 2 YOE, switching to product company |
| **Location** | Bangalore |
| **Tech comfort** | Medium-high |
| **Placement timeline** | Active job search, 2–3 months |

### Background

Priya has industry experience but her resume isn't optimized for ATS. She's rusty on DSA after 2 years in CRUD-heavy work. She wants quick wins on resume and targeted DSA refresh.

### Goals

- ATS-optimized resume for SDE-2 roles
- Refresh DP and graphs in 6 weeks
- Practice behavioral interviews for leadership principles

### Frustrations

- Resume tools give scores without actionable fixes
- DSA platforms don't account for her partial prior knowledge
- HR round prep is scattered across blogs

### How InterviewGPT Helps

- Resume analyzer with keyword gaps and AI rewrite suggestions
- Difficulty-filtered DSA with topic tags (DP, Graphs)
- Behavioral mock interview mode with STAR feedback

### Key Features Used

Resume Analyzer · DSA Arena · Mock Interviewer (Behavioral) · Dashboard

## Anti-Personas (Not Target Users)

- **Casual browsers** — No free-tier content without registration for core features
- **Enterprise HR teams** — Not an applicant tracking system (ATS) for recruiters
- **Competitive programming elites** — Codeforces-level contests out of scope for V1
